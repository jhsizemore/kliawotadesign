# Books XIII–XVI editorial audit

**Date:** 23 September 2026

## Outcomes
- 5 new exact Butler quote candidates.
- 14 new source-led adaptation candidates.
- Existing Hunting Hawk quote retained.

## Emotional sequence
1. Book XIII — home is physically reached before it can be recognised.
2. Book XIV — loyalty is demonstrated while identity remains hidden.
3. Book XV — the son returns under active threat.
4. Book XVI — father and son recognise each other, grieve, then immediately turn recognition into planning.

## Key distinctions
- Athena's Intervention = specific appearance/disguise action.
- Athena, Far-Seeing Guide = systemic control over visibility, timing and safe revelation.
- Athena and Odysseus, Minds Alike = intellectual kinship and shared deception.
- Eumaeus Shares His Supper = giving before belief.
- Test the Swineherd = a false story used to reveal true character.
- Eumaeus, Loyal Swineherd = loyalty with no expectation of reward.
- Eumaeus's Hut = refuge becoming command post.
- Voyage's End = homecoming completed while Odysseus is still asleep.
- Homeward Harbor = familiar home rendered strange by withheld context.
