## Structure

`projects[]` stores public descriptions, evidence-supported status, optional public `href`/`tools`, or `unreleased: true` with no link. DJ Radar uses a dated `metric` object. `posts[]` stores coverage and actual publication dates, prose, status and optional public `sources`. All strings are escaped by the generator. It replaces marked regions in the homepage and writes the standalone archive. Do not edit generated post/project markup directly; regenerate it from the data. The seven established social/community links remain separately maintained in the homepage.
